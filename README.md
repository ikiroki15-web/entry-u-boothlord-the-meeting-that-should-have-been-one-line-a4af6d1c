A make.fun entry for [The Meeting That Should Have Been One Line](https://make.fun/competitions/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

## What it does

`main.ts` writes a single sentence to `/output/entry.txt` — the one line
that could have replaced an entire pointless meeting. The decision is
already made, the owner is already assigned, the deadline is already set,
so the meeting has nothing left on its agenda except explaining why
everyone is still sitting in the room.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt` (deterministic, no network, no secrets).
